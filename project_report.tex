\section{Introduction}
The \textbf{AI-Powered Smart Retail Platform} is an end-to-end application designed to automate and simplify daily store operations. The platform integrates Computer Vision and Natural Language Processing models into a single user interface. 

The complete codebase is publicly hosted on GitHub at: \\
\url{https://github.com/SuyashSoni10/AI-Retail-Platform}.

The platform is divided into two parts:
\begin{enumerate}
    \item \textbf{Backend Server (FastAPI):} Runs the AI inference scripts and handles data endpoints.
    \item \textbf{Frontend Interface (Streamlit):} Provides a web dashboard for store managers and self-checkout kiosks.
\end{enumerate}

---

\section{Project Architecture \& Data Flow}
The project uses a clean modular structure. Data flows from the user inputs on the dashboard down to the ML models, returning results instantly:

\begin{enumerate}
    \item \textbf{User Interaction:} The user interacts with the Streamlit frontend UI (webcam, files, reviews, or chat inputs).
    \item \textbf{API Calls:} Streamlit packs the user input and sends a network request to the FastAPI server endpoints.
    \item \textbf{Router Routing:} FastAPI catches the call in its endpoint routers (\texttt{vision.py}, \texttt{nlp.py}, or \texttt{chatbot.py}).
    \item \textbf{Service Execution:} The router calls the respective Service script (\texttt{cv\_service.py}, \texttt{nlp\_service.py}, or \texttt{chatbot\_service.py}).
    \item \textbf{Model Loading \& Prediction:} The Service script loads the trained model binary (from the \texttt{app/models/} folder), processes the input data (resizes images, cleans review text, or encodes chat messages), executes model predictions, and returns formatted JSON data back to the user interface.
\end{enumerate}

\section{Detailed Notebook Explanations}
The models are trained using Jupyter Notebooks inside the \texttt{notebooks/} folder. Each notebook handles a specific machine learning task:

\subsection{01 Product Classifier Training Notebook}
\begin{itemize}
    \item \textbf{Purpose:} Trains a Deep Learning classifier to identify product items for automated checkout registers.
    \item \textbf{How it works:}
        \begin{enumerate}
            \item Loads the \textbf{Retail Product Checkout (RPC)} dataset.
            \item Identifies the top 5 most common categories (\textit{bags, clothing, electronics, groceries, shoes}) to keep training fast.
            \item Employs a pre-trained \textbf{MobileNetV2} base model (using ImageNet weights) as a feature extractor.
            \item Applies data augmentation (random horizontal flips and rotations) to prevent overfitting.
            \item Sets Keras mixed precision (\texttt{mixed\_float16}) to speed up training on a Tesla T4 GPU.
            \item Saves the trained network configuration and weights as \texttt{product\_classifier.h5}.
        \end{enumerate}
\end{itemize}

\subsection{02 Face Recognition Setup Notebook}
\begin{itemize}
    \item \textbf{Purpose:} Configures the facial loyalty database to detect returning customers at store kiosks.
    \item \textbf{How it works:}
        \begin{enumerate}
            \item Scans the \textbf{Labeled Faces in the Wild (LFW)} dataset directory.
            \item Automatically selects people having 3 or more photos, choosing the top 5 people.
            \item Extracts facial regions from photographs using a pre-trained OpenCV Haar Cascade model.
            \item Trains an OpenCV \textbf{LBPHFaceRecognizer} (or extracts embeddings via Python \texttt{face\_recognition} dlib dependencies).
            \item Serializes the customer ID mapping database to \texttt{face\_db.pkl}.
        \end{enumerate}
\end{itemize}

\subsection{03 Sentiment Model Training Notebook}
\begin{itemize}
    \item \textbf{Purpose:} Classifies customer written reviews to measure overall store satisfaction.
    \item \textbf{How it works:}
        \begin{enumerate}
            \item Loads the raw \textbf{Amazon Fine Food Reviews} CSV dataset.
            \item Maps reviewer scores (ratings 1--5) to Positive ($\ge 4$), Neutral ($= 3$), and Negative ($\le 2$) categories.
            \item Extracts 10,000 balanced review samples per category to ensure unbiased predictions.
            \item Cleans text (lowercasing, punctuation stripping, and stopwords removal).
            \item Splits text data into Train and Test datasets *before* vectorization to prevent data leakage.
            \item Vectorizes text using **TF-IDF** (n-grams range 1 to 2) and trains a **Logistic Regression** classifier.
            \item Saves the outputs as \texttt{sentiment\_model.pkl} and \texttt{vectorizer.pkl}.
        \end{enumerate}
\end{itemize}

\subsection{04 Chatbot Intent Training Notebook}
\begin{itemize}
    \item \textbf{Purpose:} Trains a virtual assistant to handle common customer retail inquiries.
    \item \textbf{How it works:}
        \begin{enumerate}
            \item Loads patterns and tags from the store's custom \texttt{intents.json} file.
            \item Cleans patterns, extracts keywords, and compiles a binary Bag-of-Words representation.
            \item Trains a simple Classification Model to map input queries to intention tags.
            \item Packages the trained classifier and response rules into \texttt{chatbot\_model.pkl}.
        \end{enumerate}
\end{itemize}

\section{Chatbot FAQ Intents Schema}
The virtual support bot uses intent classification to understand what a customer wants. The categories (intents) defined in \texttt{data/intents.json} include:

\begin{itemize}
    \item \textbf{\texttt{greeting}:} Welcomes customers. Matching queries include: \textit{"Hi", "Hello", "What's up"}.
    \item \textbf{\texttt{goodbye}:} Closes conversations. Matching queries include: \textit{"Bye", "See you later", "Goodbye"}.
    \item \textbf{\texttt{thanks}:} Acknowledges helpful support. Matching queries include: \textit{"Thank you", "Thanks", "Awesome"}.
    \item \textbf{\texttt{hours}:} Returns business operation hours. Matching queries include: \textit{"When do you open?", "Are you open today?"}.
    \item \textbf{\texttt{location}:} Provides store address. Matching queries include: \textit{"Where are you located?", "What is your address?"}.
    \item \textbf{\texttt{payment\_methods}:} Answers payment options. Matching queries include: \textit{"Do you accept Apple Pay?", "Can I pay with credit card?"}.
    \item \textbf{\texttt{returns}:} Guides customers through product returns. Matching queries include: \textit{"How do I get a refund?", "What is your return policy?"}.
    \item \textbf{\texttt{track\_order}:} Tracks parcel deliveries. Matching queries include: \textit{"Where is my order?", "Can I track my shipment?"}.
    \item \textbf{\texttt{loyalty\_program}:} Explains point benefits. Matching queries include: \textit{"How do I join the loyalty club?", "What are loyalty points?"}.
\end{itemize}

\section{Cross-Environment Model Deserialization Fix}
During project setup, loading the Kaggle-trained \texttt{product\_classifier.h5} file locally failed with a \texttt{ValueError: Unknown layer: TrueDivide}. 

This is because newer Keras 3 versions on Kaggle automatically compile inline division (\texttt{x / 127.5}) and subtraction (\texttt{x - 1.0}) operations inside MobileNetV2's preprocessing layer into standalone \texttt{TrueDivide} and \texttt{Subtract} layers. 

We solved this locally by creating custom class overrides inside the service layer to intercept and format arguments during the model load:

\begin{lstlisting}[language=Python, caption=Custom Keras Override Layers]
class TrueDivide(Layer):
    def call(self, x, y=1.0):
        return x / y
    def __call__(self, *args, **kwargs):
        tensor = args[0]
        divisor = args[1] if len(args) > 1 else 1.0
        kwargs['y'] = divisor
        return super().__call__(tensor, **kwargs)
\end{lstlisting}

\begin{enumerate}

    \item \textbf{Self-Checkout Product Kiosk:} Identifies scanned item packagings.
    \item \textbf{Feedback Center:} Classifies review text sentiments.
    \item \textbf{FAQ Bot Agent:} Direct chat bubble UI to talk to the AI support agent.
    \item \textbf{Analytics Dashboard:} Plots charts showing aggregate visitor analytics.
\end{enumerate}
